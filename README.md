# Tienda React - Taller JavaScript aplicado a React

Aplicación de catálogo de productos creada con **Vite + React + JavaScript**.

## Cómo ejecutar

```bash
npm install
npm run dev
```

Abre la URL que aparece en la terminal (normalmente http://localhost:5173).

## Estructura principal

- `practica-js.js` → Todos los ejercicios de JavaScript (funciones, arrays, map, filter, reduce, etc.)
- `src/data/productos.js` → Datos de los productos
- `src/components/ProductoCard.jsx` → Componente de tarjeta de producto
- `src/App.jsx` → Componente principal (filtra, reduce, some, map + key)

## Commits sugeridos

1. `feat: ejercicios base de JavaScript`
2. `feat: mostrar productos con React`
3. `feat: sección de disponibles + some/reduce`
